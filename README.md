- 解决的业务问题
通过人群精细化挖掘的路径，解决下述问题
场景一. 已通过AB实验有结论，想进一步改善优化结论
1. 问题：当前一个或多个策略/功能，在目标值上无显著收益
  例如：优惠券弹窗，并未让gmv增长，可尝试使用本文方法，挖掘出在优惠券弹窗刺激下，原先不会下单的转而产生下单行为的群体，只对他们开放优惠券弹窗，对那些在优惠券弹窗刺激下，反而阻碍其下单的群体，关闭优惠券弹窗，进而刺激整体gmv增长。

2. 问题：当前一个或多个策略/功能，在目标值上有显著收益，但roi不达标
  例如：优惠券弹窗，让gmv显著增长，但同时roi过低，不达标，可能是部分薅羊毛用户存在，买得太便宜了，可尝试使用本文方法，挖掘出roi较高的群体，只对这部分用户开放优惠券弹窗，来保证整体roi达标

3. 问题：当前一个或多个策略/功能，在目标值上有显著收益，但另一个护栏指标显著负向
  例如：优惠券弹窗，让gmv显著增长了，但是让用户留存下降了，可能是大部分用户因为弹窗出现，确实更多下单了，但是弹窗形式让部分用户体验非常不好，用户流失，可尝试使用本文方法，挖掘出那些不对弹窗形式反感，且在优惠券刺激下，更愿意下单的群体，只对他们开放当前弹窗。

4. 问题：当前一个或多个策略/功能，在目标值上有显著收益，想进一步扩大收益的。
  例如：优惠券弹窗，让gmv显著增长了，想进一步扩大收益，这其中可能存在一部分因为弹窗不下单的用户，只要把这部分用户找到，剔除掉，就能进一步刺激gmv增长，可尝试本文方法，找到这部分用户，剔除后，只对其余用户开放弹窗。

场景二. AB实验未开启，想确保通过一次实验就拿收益
1. 问题：当前一个或多个策略/功能，期望在目标值上拿收益
2. 问题：当前一个或多个策略/功能，期望在ROI或者一定约束下拿收益

举例说明
结合现在大家实际面对到的业务问题，有许多场景和问题可用本文工具方法解决，以人群精细化为例，例如
商城：多玩法人群差异化挖掘，为每个用户适配最合适的玩法，最大限度刺激其gmv增长
权益：权益人群精准触达，挖掘对权益敏感的人群，曝光和增加权益会在当前人群上产生最大gmv增量
营销：bonus直接发放人群挖掘，挖掘哪些用户发放直接发放bonus后，会有gmv增量
购前：instant物流方式获益人群挖掘，挖掘哪些用户发开放instant物流方式后，会有gmv增量
售后：售后高价值人群挖掘，通过观测数据，挖掘经历过售后链路后，有gmv增益的人群
......
